# Antigravity 에게 글 작성 부탁하기

Claude 가 초안을 작성하고, Antigravity 가 뒤이어 서술을 개선한다. 어휘 규격을
문서로 옮겨 적는 대신 Antigravity 를 그대로 호출한다.

**대상 파일을 제자리에서 덮어쓴다.**

## 가드레일

### 1. 명시적 호출로만 작동한다

**사용자가 이 스킬을 직접 부를 때만 실행한다.** 문서를 작성했거나 수정했다는
이유로 스스로 판단해 호출해서는 안 된다. 문체를 다듬을 필요가 있어 보여도
사용자가 부르기 전까지는 실행하지 않는다.

대상 파일을 덮어쓰는 작업이며, 되돌리는 책임이 사용자에게 있기 때문이다.

### 2. 절대경로만 사용한다

`agy` 는 셸의 현재 디렉터리가 아니라 **자체 프로젝트 컨텍스트**를 기준으로
상대경로를 해석한다. 설정에 `allowNonWorkspaceAccess: true` 가 켜져 있으면 작업
공간 밖에도 쓴다.

**실제로 사고가 발생했다.** 저장소 루트에서 `docs/sub.md` 로 호출했더니, 마지막에
쓰던 다른 저장소의 파일을 덮어썼다. `--dangerously-skip-permissions` 가 붙어 있어
확인 절차 없이 진행되었다.

절대경로를 프롬프트에 넣으면 이 문제가 발생하지 않는다.

### 3. 파일 하나마다 한 번씩 호출한다

여러 파일을 한 프롬프트에 넣지 않는다.

## 절차

### 1. 대상 파일을 확정한다

**사용자가 경로를 주지 않는다.** 대화 맥락에서 직전에 작성하거나 수정한 파일을
스스로 판단해 채운다.

| 상황 | 판단 |
| :--- | :--- |
| 직전에 파일 하나를 작성했다 | 그 파일을 대상으로 한다 |
| 여러 파일을 작성했다 | 어느 것인지 사용자에게 묻는다 |
| 사용자가 파일을 지목했다 | 그 파일을 대상으로 한다 |
| 판단할 근거가 없다 | 묻는다. 추측해서 덮어쓰지 않는다 |

확정한 뒤 절대경로로 변환한다.

```sh
realpath <파일>
```

### 2. 호출한다

```sh
agy --print-timeout=280s --dangerously-skip-permissions --print="<절대경로> 를 개선해서 같은 경로에 저장하세요.

규칙:
1. 파일에 이미 적혀 있는 사실에 근거해서 작성합니다.
2. 이모지를 제거합니다.
3. 문서를 읽고 성격을 먼저 파악한 뒤, 그 성격에 맞는 형식으로 서술 방식을 개선해 주세요. (기술 문서, 아키텍처 문서, 보고서 등)
4. 과장된 표현을 조심하세요."
```

`--print` 는 값을 붙여서 전달해야 한다. Go 플래그 문법이므로 `--print '내용'` 처럼
띄어 쓰면 다음 인자를 프롬프트로 오인한다.

`--print-timeout` 의 기본값은 5분이다. 200줄을 넘는 문서는 늘린다.

### 3. 보고한다

어느 파일을 어떤 경로로 호출했는지, `agy` 가 무엇을 바꿨다고 보고했는지 전달한다.
**결과 검증은 사용자가 한다.**

## 전제

`agy` 가 PATH 에 존재해야 한다. 없으면 사용자에게 알리고 중단한다.

```sh
command -v agy
```

## 실패 처리

| 증상 | 원인과 조치 |
| :--- | :--- |
| `--print took "--print-timeout" as its prompt` | 플래그에 값을 붙이지 않았다. `--print='...'` 형태로 고친다 |
| 대상 파일이 바뀌지 않았다 | 상대경로로 호출했을 가능성이 높다. 다른 위치를 확인하고 절대경로로 재시도한다 |
| 시간이 초과되었다 | `--print-timeout` 을 늘린다 |
